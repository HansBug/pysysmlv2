# OMG Release Fixture Corpus

This directory contains a verbatim local test-fixture copy of the SysML v2 example, training, and validation models under `sysml/src/examples`, `sysml/src/training`, and `sysml/src/validation` from the `Systems-Modeling/SysML-v2-Release` GitHub release branch `2026-05`, commit `de1070ae8e79c21532b8004fc663d47b35d0e9fa`.

The upstream release README states that the included SysML v2 models are licensed under Eclipse Public License 2.0 by their listed copyright holders; the complete upstream license text is copied unchanged as `LICENSE-EPL-2.0.txt`. This fixture corpus is repository-owned test data so the test suite does not read a submodule or clone during collection. The `2026-05` release is an incremental GitHub release containing Beta 1 material, not evidence that OMG has formally published SysML 2.1.

The original source, release metadata, and copyright holder list are available at https://github.com/Systems-Modeling/SysML-v2-Release/tree/2026-05.
