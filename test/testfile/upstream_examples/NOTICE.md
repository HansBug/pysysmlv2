# Fixture provenance

`camera.sysml`, `toaster-system.sysml`, and `vehicle-model.sysml` are verbatim
test fixtures copied from `daltskin/sysml-v2-grammar` at commit
`7292dc39983a6d263d14f8f6689de0f3b35db5eb`, specifically its `examples/`
directory. They are kept here so the unit test suite is self-contained and
does not read assets from the grammar submodule at test time.
